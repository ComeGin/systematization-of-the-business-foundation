## 文案

### 9.5.1 動きと装飾の例外（Web サイト）

Web サイトに限り、**トップとサービスのページ**では、動き・光・立体の表現について本書の一部の規定を例外とする。
「この人に任せて大丈夫か」を判断する前の最初の数秒に期待を作り、§2.7 の「近い ― 顔と名前で仕事をする」を写真より一歩進めて体験にするためである。
それ以外のページは本書のとおり「誠実・静か」を保つ。

#### ページの区分

| 区分 | ページ | 表現 |
| ---- | ------ | ---- |
| **A（華やか）** | トップ、サービス一覧、サービス詳細（環境構築・開発・コンサルティング・業務提携） | 光・立体・粒子・文字のにじみ出しまで使ってよい（下の「例外にするもの」） |
| **B（静か）** | 上記と C 以外のすべて（料金・会社紹介・お問い合わせ・ブログ・アクセシビリティ方針・サイトマップなど） | 本書のとおり。動きは「下からわずかに現れる・線が引かれる・数字が切り替わる」程度で、光り物・立体は使わない |
| **C（動きなし）** | プライバシーポリシー、特定商取引法に基づく表記 | 動き・アバターを出さない |

#### 例外にするもの（A のページだけ）

1. **§2.7 ブランドパーソナリティの「誠実 / 静か — 装飾で押さない」**: 動き・光・立体の装飾を使ってよい。
2. **§5.4 配色比率（青は面積の 10% まで）**: 光（スポットライト・光の筋・光の縁・粒・地球儀）の表現のために、青の面積が 10% を超えてよい。
3. **§7.3 角丸・罫・影（影は 3 段階まで。立体表現を重ねない）**: カードの傾き・浮き・ピンなどの立体表現を使ってよい。影は `shadow.lg` までを使う。
4. **§9.5 のファーストビュー（背景 `neutral.50`、`navy.700` の H1）**: A のファーストビューは `navy.900` の地に白い見出しとする。

#### アバター

代表の VRoid アバターを、C を除く**全ページ（A と B）**の左下に出す。代表の分身として、顔と名前で仕事をする姿勢を体験にするためである。
B のページでの例外はアバターだけとする。アバターは情報を持たない飾りで、止める・しまうことができる。

#### どのページでも守るもの（例外にしない）

- **色はパレット（§5.2）だけ。** 光も `brand.sky`・`brand.blue`・`brand.gradient` から取る。パレット外の色を足さない（§5.5-1）。
- **本文の文字のコントラスト 4.5:1**（§1.3 の優先順位 1「読めること」）。動きの上に文字を重ねるときは、動きを含めて測る。
- **ロゴの禁止例（§4.6）。** 回転・傾斜・光彩・ドロップシャドウをロゴにかけない。傾く・浮くカードの中にロゴを置かない。他社のロゴを新しく載せない（ツールの一覧は文字のバッジで見せる）。
- **書体・文字サイズ・組版（§6）。**
- **動きのアクセシビリティ。** 5 秒を超えて自動で動くものには一時停止のボタンを付ける。動きを減らす設定（`prefers-reduced-motion`）では止める。点滅は 1 秒に 3 回まで。見出し・本文は動きで隠さない。

## 反映の前に決めてほしいこと

1. **§5.5-6「透明度でブランドカラーを薄める」を例外に含めるか。** A の光（スポットライト・光の縁など）は、パレットの色を透明度（`color-mix`）で薄めて描いている。含めるなら「例外にするもの」に 5 として「光の表現に限り、§5.5-6 の透明度での薄めを使ってよい（面・文字・罫には使わない）」を足す。含めないなら、光をランプの 50〜200 の色で描き直す必要がある（`05-motion-spec.md` の MO-11）。
2. **§9.5 のファーストビューの例外（上の 4）で合っているか。** A のヒーローを `navy.900` の地にしたのは試作で承認した手触り（設計書の U-6）だが、計画が ADR-29 に挙げた例外の節は §2.7・§5.4・§7.3 だけで、§9.5 は入っていなかった。実装と U-6 に合わせて、ADR-29 の決定 2 とこの文案に足した。
3. **§1.2 適用範囲・付録 A（公開前チェックリスト）にも触れるか。** 付録 A に「A のページの動きが 9.5.1 の範囲に収まっているか」の項を足す案がある（この文案には入れていない）。
