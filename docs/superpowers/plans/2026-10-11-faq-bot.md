# faq-bot（Chatwoot の FAQ ボット）と ADR-26 の実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Chatwoot の受信箱「Web サイト」で、訪問者の質問に Web サイトの FAQ の原文で答え、答えられないときは人に引き継ぐエージェントボット（本番は Lambda）を作る。

**Architecture:** Astro のビルドが `faq.json` を出し、`backend/faq-bot` がそれを読んで文字 2-gram の Dice 係数で照合する。Chatwoot のエージェントボットの Webhook を署名で検証し、ボットのトークンで返信・ラベル・ステータスを操作する。処理の本体（`handler.ts`）を入口から切り離し、開発は Node の HTTP サーバー（3107）、本番は VPC の外の Lambda（関数 URL）から呼ぶ。データの置き場は持たない。

**Tech Stack:** TypeScript（pnpm 11・Node 22）・zod v4・vitest 5.0.1・esbuild（Lambda のバンドル）・AWS SAM（`AWS::Serverless::Function`）・Chatwoot v4.18.0 の Application API・Astro 7 の静的エンドポイント。

**Spec:** `docs/superpowers/specs/2026-10-11-faq-bot-design.md`（実行者は計画と仕様の両方を読む）

## Global Constraints

- パッケージマネージャは **pnpm**（`npm` を使わない。`.claude/rules/package-manager.md`）。Node は 22 以上。
- **`git commit`・`git push` などリポジトリの状態を変える git コマンドを使わない**（`.claude/rules/git.md`）。各タスクの最後は差分の確認だけで、コミットはユーザーが行う。
- **ビルド（`pnpm build`・`sam build`）とデプロイ（`sam deploy`）を実行しない**（`.claude/rules/build-deploy.md`）。型の確認は `pnpm typecheck`、テンプレートの確認は cfn-lint（`validate_cloudformation_template`）で行う。Astro の `faq.json` は `astro dev` で確かめる。
- テストはユーザーの明示の指示で作る（単体＋結合。仕様の D5）。単体テストの決まり: 対象ごとに `describe("正常系")` / `describe("異常系")`、各公開関数・エンドポイントに `空入力: ` で始まるケース、異常系の名前は `入力: `（検証・形式）か `サーバ: `（上流の 4xx/5xx・通信失敗・タイムアウト・AWS SDK の例外）で始める。外部はモック。`testTimeout` / `hookTimeout` は `30_000`。テストで見つけた src のバグは src を直さず `it.todo` と直上のコメントで残す。
- 結合テストは開発スタック（127.0.0.1 の Chatwoot）を本物として使い、それ以外（`faq.json`）はテスト内の偽の HTTP サーバー。テストデータは `it-` 接頭辞で作り、`afterAll` で消す。
- `.env`・`samconfig.toml`・`secrets/` を読まない・書かない（フックが拒否する）。値が要るときは `.env.example` を見る。`grep -r` を `.env` のあるディレクトリに向けない（`rg` を使う）。
- ドキュメント・コメント・ログの文言は日本語。
- **ログに訪問者のメッセージ本文・氏名・メールアドレス・トークンを出さない**（仕様 8 節）。
- 既定値（仕様の値をそのまま）: ポート **3107**、タイムアウト **4 秒**（Lambda）、予約同時実行数 **5**、`FAQ_REFRESH_SECONDS` **600**、`FAQ_MATCH_HIGH` **0.5**、`FAQ_MATCH_LOW` **0.25**、`FAQ_MATCH_MARGIN` **0.1**、署名の時刻の許容 **300 秒**、本文の上限 **64 KB**、質問の切り詰め **1000 文字**、候補 **3 件**。
- ラベル: `faq-answered`・`faq-unmatched`・`faq-handoff`。選択肢の値: FAQ の `id`・`__none`・`__handoff`・`__resolved`。
- 文言（仮。仕様 14 節で `R3` が見直す）: 回答の後ろ「詳しくは: <url>」、候補「次のどれに近いですか？」、引き継ぎ「担当者におつなぎします。順番にお返事しますので、このままお待ちください。」、解決「お役に立ててよかったです。ほかにもご質問があれば、いつでもどうぞ。」、選択肢「解決しました」「担当者に相談する」「どれにも当てはまらない」。
- Chatwoot のボットのトークンで呼べる API は、会話の `show`・`toggle_status`、メッセージの `create`、ラベルの `create` だけを使う（メッセージの一覧は呼べない）。

## Review Focus

仕様が明示していないが、使う人がまず踏みそうな入力と、期待する振る舞い（それぞれのテストを担当のタスクに入れてある）:

1. **記号・絵文字だけの発言（「？？？」「👍」）** → 正規化で空になる。落ちずに `faq-unmatched` で人に引き継ぐ（Task 6 の decide）。
2. **全角・半角の違い（「４時間」と「4時間」、「ＡＩ」と「AI」）** → NFKC で同じに扱い、同じスコアになる（Task 2 の matcher）。
3. **古い選択肢を後から押す（訪問者が次の質問を送った後に、前の候補のボタンを押す）** → 古いイベントとして何もしない（Task 7 の execute）。
4. **候補を出した後に `faq.json` から消えた FAQ を選ぶ** → 存在しない `id` は `faq-unmatched` で引き継ぐ（Task 6 の decide）。
5. **`faq.json` の更新で CloudFront が HTML（エラーページ）を 200 で返す** → JSON として読めないので、直前の索引を使い続ける（Task 3 の store）。

import { beforeEach, describe, expect, it, type MockInstance, vi } from "vitest";
import { loadConfig } from "../src/config.js";

const BASE_ENV = {
  CHATWOOT_BASE_URL: "http://127.0.0.1:3100",
  CHATWOOT_ACCOUNT_ID: "1",
  CHATWOOT_BOT_TOKEN: "bot-token-value",
  CHATWOOT_BOT_SECRET: "0123456789abcdef0123",
  FAQ_URL: "http://localhost:4321/faq.json",
} as const;

class ExitCalled extends Error {
  constructor(readonly code: number | string | null | undefined) {
    super(`process.exit(${code})`);
  }
}

let stderr: MockInstance<typeof console.error>;
let exit: MockInstance<typeof process.exit>;

beforeEach(() => {
  stderr = vi.spyOn(console, "error").mockImplementation(() => {});
  exit = vi.spyOn(process, "exit").mockImplementation((code) => {
    throw new ExitCalled(code);
  });
});

/** 検証に失敗させ、stderr に出た文面を返す */
function loadInvalid(env: Record<string, string>): string {
  expect(() => loadConfig(env)).toThrow(ExitCalled);
  expect(exit).toHaveBeenCalledWith(1);
  return stderr.mock.calls.map((args) => args.join(" ")).join("\n");
}

describe("loadConfig", () => {
  describe("正常系", () => {
    it("必須の 5 つだけで起動でき、残りは既定値になる", () => {
      expect(loadConfig({ ...BASE_ENV })).toMatchObject({
        HOST: "127.0.0.1",
        PORT: 3107,
        CHATWOOT_ACCOUNT_ID: 1,
        FAQ_REFRESH_SECONDS: 600,
        FAQ_MATCH_HIGH: 0.5,
        FAQ_MATCH_LOW: 0.25,
        FAQ_MATCH_MARGIN: 0.1,
      });
    });

    it("CHATWOOT_BASE_URL の末尾の / を外す", () => {
      expect(loadConfig({ ...BASE_ENV, CHATWOOT_BASE_URL: "https://chat.comegin.com/" }).CHATWOOT_BASE_URL).toBe("https://chat.comegin.com");
    });

    it("空入力: 既定値のある変数が空なら既定値を使う", () => {
      const config = loadConfig({ ...BASE_ENV, PORT: "", FAQ_MATCH_HIGH: "", FAQ_REFRESH_SECONDS: " " });
      expect(config.PORT).toBe(3107);
      expect(config.FAQ_MATCH_HIGH).toBe(0.5);
      expect(config.FAQ_REFRESH_SECONDS).toBe(600);
    });
  });

  describe("異常系", () => {
    it("空入力: 必須の変数が無いと、変数名を出して終了する", () => {
      const out = loadInvalid({});
      for (const name of ["CHATWOOT_BASE_URL", "CHATWOOT_ACCOUNT_ID", "CHATWOOT_BOT_TOKEN", "CHATWOOT_BOT_SECRET", "FAQ_URL"]) {
        expect(out).toContain(name);
      }
    });

    it("入力: 値（秘密値）は出力しない", () => {
      const out = loadInvalid({ ...BASE_ENV, CHATWOOT_BOT_SECRET: "xyzSECRET" });
      expect(out).toContain("CHATWOOT_BOT_SECRET");
      expect(out).not.toContain("xyzSECRET");
    });

    it("入力: http・https 以外の URL は受け付けない", () => {
      expect(loadInvalid({ ...BASE_ENV, FAQ_URL: "ftp://example.com/faq.json" })).toContain("FAQ_URL");
    });

    it("入力: しきい値が 0〜1 の外なら受け付けない", () => {
      expect(loadInvalid({ ...BASE_ENV, FAQ_MATCH_HIGH: "1.5" })).toContain("FAQ_MATCH_HIGH");
    });

    it("入力: FAQ_MATCH_LOW が FAQ_MATCH_HIGH より大きいと受け付けない", () => {
      expect(loadInvalid({ ...BASE_ENV, FAQ_MATCH_HIGH: "0.5", FAQ_MATCH_LOW: "0.6" })).toContain("FAQ_MATCH_LOW");
    });

    it("入力: CHATWOOT_ACCOUNT_ID が正の整数でないと受け付けない", () => {
      expect(loadInvalid({ ...BASE_ENV, CHATWOOT_ACCOUNT_ID: "abc" })).toContain("CHATWOOT_ACCOUNT_ID");
    });
  });
});

```ts
import { QUESTION_SUFFIXES } from "../constants.js";

// 空白・句読点・記号（Unicode の P と S。絵文字を含む）
const STRIP = /[\s\p{P}\p{S}]/gu;
const SUFFIXES = [...QUESTION_SUFFIXES].sort((a, b) => b.length - a.length);

/** 照合用の正規化。NFKC → 小文字 → 空白・句読点・記号を削る → 末尾の定型句を削る（文が丸ごと消えるときは削らない） */
export function normalize(text: string): string {
  let out = text.normalize("NFKC").toLowerCase().replace(STRIP, "");
  for (let changed = true; changed; ) {
    changed = false;
    for (const suffix of SUFFIXES) {
      if (out.length > suffix.length && out.endsWith(suffix)) {
        out = out.slice(0, -suffix.length);
        changed = true;
        break;
      }
    }
  }
  return out;
}

/** 文字 n-gram の集合。サロゲートペアを 1 文字として数える */
export function grams(text: string, n: 1 | 2): Set<string> {
  const chars = Array.from(text);
  const out = new Set<string>();
  if (n === 1) {
    for (const c of chars) out.add(c);
    return out;
  }
  for (let i = 0; i + 1 < chars.length; i++) out.add(`${chars[i]}${chars[i + 1]}`);
  return out;
}

/** Dice 係数 2|A∩B| / (|A|+|B|)。どちらかが空なら 0 */
export function dice(a: ReadonlySet<string>, b: ReadonlySet<string>): number {
  if (a.size === 0 || b.size === 0) return 0;
  let common = 0;
  for (const g of a) if (b.has(g)) common++;
  return (2 * common) / (a.size + b.size);
}

export interface IndexedEntry<T> {
  readonly item: T;
  readonly g1: ReadonlySet<string>;
  readonly g2: ReadonlySet<string>;
}

export function buildIndex<T>(items: readonly T[], key: (item: T) => string): IndexedEntry<T>[] {
  return items.map((item) => {
    const norm = normalize(key(item));
    return { item, g1: grams(norm, 1), g2: grams(norm, 2) };
  });
}

export interface Ranked<T> {
  readonly item: T;
  readonly score: number;
}

/** 質問に近い順に並べる。1 文字の質問は 1-gram で比べる。正規化して空なら [] */
export function rank<T>(query: string, index: readonly IndexedEntry<T>[]): Ranked<T>[] {
  const q = normalize(query);
  const length = Array.from(q).length;
  if (length === 0) return [];
  const unigram = length < 2;
  const qg = grams(q, unigram ? 1 : 2);
  return index
    .map((entry, position) => ({ item: entry.item, score: dice(qg, unigram ? entry.g1 : entry.g2), position }))
    .sort((a, b) => b.score - a.score || a.position - b.position)
    .map(({ item, score }) => ({ item, score }));
}

export function sequenceFetch(...responses: (Response | Error)[]): typeof fetch & { calls: number } {
  const fn = (async () => {
    fn.calls++;
    const next = responses.shift();
    if (!next) throw new Error("想定外の呼び出し");
    if (next instanceof Error) throw next;
    return next;
  }) as typeof fetch & { calls: number };
  fn.calls = 0;
  return fn;
}

/** 照合の索引は「context ＋ 質問」で作る（同じ質問が複数のページにあるため。仕様 5 節。context を前に置くと、質問の末尾の定型句を削れる） */
export function buildSnapshot(items: readonly FaqItem[], loadedAt: number): FaqSnapshot {
  return {
    items,
    index: buildIndex(items, (item) => `${item.context ?? ""}${item.question}`),
    byId: new Map(items.map((item) => [item.id, item])),
    loadedAt,
  };
}

export class FaqUnavailableError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "FaqUnavailableError";
  }
}

export interface FaqSource {
  current(): Promise<FaqSnapshot>;
}

export interface FaqStoreOptions {
  url: string;
  refreshMs: number;
  timeoutMs: number;
  fetchImpl?: typeof fetch;
  now?: () => number;
  warn?: (message: string) => void;
}

/** faq.json をメモリに持つ。古くなったら取り直し、失敗したら直前の索引を使い続ける（仕様 8 節） */
export class FaqStore implements FaqSource {
  #snapshot: FaqSnapshot | null = null;
  #inflight: Promise<void> | null = null;

  constructor(private readonly options: FaqStoreOptions) {}

  async current(): Promise<FaqSnapshot> {
    const now = this.#now();
    if (!this.#snapshot || now - this.#snapshot.loadedAt >= this.options.refreshMs) {
      this.#inflight ??= this.#load().finally(() => {
        this.#inflight = null;
      });
      await this.#inflight;
    }
    if (!this.#snapshot) throw new FaqUnavailableError("faq.json をまだ一度も取得できていない");
    return this.#snapshot;
  }

  #now(): number {
    return (this.options.now ?? Date.now)();
  }

  async #load(): Promise<void> {
    const fetchImpl = this.options.fetchImpl ?? fetch;
    try {
      const res = await fetchImpl(this.options.url, {
        headers: { Accept: "application/json" },
        signal: AbortSignal.timeout(this.options.timeoutMs),
      });
      if (!res.ok) throw new Error(`HTTP ${res.status}`);
      let body: unknown;
      try {
        body = await res.json();
      } catch {
        throw new Error("JSON として読めない");
      }
      const parsed = FaqDocumentSchema.safeParse(body);
      if (!parsed.success) throw new Error(`形式が違う（${parsed.error.issues[0]?.path.join(".") || "root"}）`);
      this.#snapshot = buildSnapshot(parsed.data.items, this.#now());
    } catch (error) {
      (this.options.warn ?? ((message: string) => console.error(message)))(
        `[faq] faq.json を更新できない（${this.#snapshot ? "直前の索引を使う" : "索引が無い"}）: ${(error as Error).message}`,
      );
      // 直前の索引があれば、次の更新間隔まで取り直さない（毎回の要求で取りに行かない）
      if (this.#snapshot) this.#snapshot = { ...this.#snapshot, loadedAt: this.#now() };
    }
  }
}

import { createHmac, timingSafeEqual } from "node:crypto";

export interface VerifyInput {
  secret: string;
  timestamp: string | undefined;
  signature: string | undefined;
  rawBody: Buffer;
  nowSeconds: number;
  toleranceSeconds: number;
}

export type SignatureResult = { ok: true } | { ok: false; reason: "missing" | "malformed" | "stale" | "mismatch" };

/**
 * Chatwoot のエージェントボットの Webhook の署名を確かめる（lib/webhooks/trigger.rb）。
 * X-Chatwoot-Signature: sha256=HMAC-SHA256(secret, "<X-Chatwoot-Timestamp>.<生の本文>")。本文は解析する前のバイト列で計算する
 */
export function verifySignature(input: VerifyInput): SignatureResult {
  const { secret, timestamp, signature, rawBody, nowSeconds, toleranceSeconds } = input;
  if (!timestamp || !signature) return { ok: false, reason: "missing" };
  if (!/^\d{1,12}$/.test(timestamp)) return { ok: false, reason: "malformed" };
  const match = /^sha256=([0-9a-f]{64})$/.exec(signature);
  if (!match?.[1]) return { ok: false, reason: "malformed" };
  if (Math.abs(nowSeconds - Number(timestamp)) > toleranceSeconds) return { ok: false, reason: "stale" };
  const expected = createHmac("sha256", secret).update(`${timestamp}.`).update(rawBody).digest();
  return timingSafeEqual(expected, Buffer.from(match[1], "hex")) ? { ok: true } : { ok: false, reason: "mismatch" };
}

import * as z from "zod/v4";
import { MAX_QUESTION_CHARS } from "../constants.js";

// Message#webhook_data の必要な部分だけ（他の項目は無視する）。conversation.id は display_id
const MessagePayload = z.object({
  event: z.enum(["message_created", "message_updated"]),
  id: z.number().int().positive(),
  content: z.string().nullish(),
  message_type: z.string(),
  content_type: z.string().nullish(),
  content_attributes: z
    .object({ submitted_values: z.array(z.object({ value: z.string().min(1).max(100) }).passthrough()).nullish() })
    .passthrough()
    .nullish(),
  private: z.boolean().nullish(),
  sender: z.object({ type: z.string().nullish() }).passthrough().nullish(),
  account: z.object({ id: z.number().int().positive() }).passthrough(),
  conversation: z.object({ id: z.number().int().positive() }).passthrough(),
});

export interface EventTarget {
  readonly accountId: number;
  readonly conversationId: number;
  readonly messageId: number;
}

export interface QuestionEvent extends EventTarget {
  readonly kind: "question";
  readonly text: string;
}

export interface SelectionEvent extends EventTarget {
  readonly kind: "selection";
  readonly value: string;
}

export type BotEvent = QuestionEvent | SelectionEvent | { readonly kind: "ignore"; readonly reason: string };

export class InvalidEventError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "InvalidEventError";
  }
}

const ignore = (reason: string): BotEvent => ({ kind: "ignore", reason });

/** Webhook の本文を、ボットが扱うイベントに変える（仕様 7.1）。扱わないものは ignore、壊れた本文は InvalidEventError */
export function parseEvent(body: unknown): BotEvent {
  const name = typeof body === "object" && body !== null ? (body as { event?: unknown }).event : undefined;
  if (typeof name !== "string") throw new InvalidEventError("event が無い");
  if (name !== "message_created" && name !== "message_updated") return ignore(`event:${name}`);

  const parsed = MessagePayload.safeParse(body);
  if (!parsed.success) throw new InvalidEventError(`形式が違う（${parsed.error.issues[0]?.path.join(".") || "root"}）`);
  const message = parsed.data;
  const target = { accountId: message.account.id, conversationId: message.conversation.id, messageId: message.id };
  if (message.private) return ignore("private");

  if (message.event === "message_created") {
    if (message.message_type !== "incoming") return ignore(`message_type:${message.message_type}`);
    const text = (message.content ?? "").trim();
    if (!text) return ignore("empty");
    return { kind: "question", ...target, text: Array.from(text).slice(0, MAX_QUESTION_CHARS).join("") };
  }

  // message_updated: ボット自身の input_select に、訪問者の選択（submitted_values）が入ったときだけ
  if (message.message_type !== "outgoing" || message.content_type !== "input_select" || message.sender?.type !== "agent_bot") {
    return ignore("not-bot-select");
  }
  const value = message.content_attributes?.submitted_values?.[0]?.value;
  if (!value) return ignore("no-selection");
  return { kind: "selection", ...target, value };
}

export interface RecordedCall {
  url: string;
  method: string;
  headers: Record<string, string>;
  body: unknown;
}

/** 呼び出しを記録し、応答を順に返す fetch（Response か Error） */
export function recordingFetch(...responses: (Response | Error)[]): { fetchImpl: typeof fetch; calls: RecordedCall[] } {
  const calls: RecordedCall[] = [];
  const fetchImpl = (async (input: string | URL | Request, init?: RequestInit) => {
    calls.push({
      url: String(input),
      method: init?.method ?? "GET",
      headers: (init?.headers ?? {}) as Record<string, string>,
      body: typeof init?.body === "string" ? JSON.parse(init.body) : undefined,
    });
    const next = responses.shift();
    if (!next) throw new Error("想定外の呼び出し");
    if (next instanceof Error) throw next;
    return next;
  }) as typeof fetch;
  return { fetchImpl, calls };
}

import * as z from "zod/v4";
import type { ConversationView, Reply } from "./types.js";

export class ChatwootApiError extends Error {
  constructor(
    readonly status: number,
    readonly operation: string,
    detail: string,
  ) {
    super(`${operation}: ${detail}`);
    this.name = "ChatwootApiError";
  }
}

/**
 * ボットのトークンで呼べる API だけ（access_token_auth_helper.rb の BOT_ACCESSIBLE_ENDPOINTS）。
 * メッセージの一覧は呼べないため、二重回答の判定は会話の show の last_non_activity_message で行う（仕様 7.4）
 */
export interface ChatwootClient {
  getConversation(conversationId: number): Promise<ConversationView>;
  sendMessage(conversationId: number, reply: Reply, inReplyTo: number): Promise<void>;
  setLabels(conversationId: number, labels: readonly string[]): Promise<void>;
  setStatus(conversationId: number, status: "open" | "resolved"): Promise<void>;
}

export interface ChatwootClientOptions {
  baseUrl: string;
  accountId: number;
  token: string;
  timeoutMs: number;
  fetchImpl?: typeof fetch;
}

const ConversationSchema = z.object({
  status: z.enum(["open", "resolved", "pending", "snoozed"]),
  labels: z.array(z.string()).nullish(),
  last_non_activity_message: z
    .object({
      id: z.number().int(),
      message_type: z.number().int(),
      sender: z.object({ type: z.string().nullish() }).passthrough().nullish(),
    })
    .passthrough()
    .nullish(),
});

export function createChatwootClient(options: ChatwootClientOptions): ChatwootClient {
  const fetchImpl = options.fetchImpl ?? fetch;
  const base = `${options.baseUrl}/api/v1/accounts/${options.accountId}/conversations`;

  async function call(method: "GET" | "POST", path: string, body?: unknown): Promise<unknown> {
    const operation = `${method} conversations${path}`;
    let res: Response;
    try {
      res = await fetchImpl(`${base}${path}`, {
        method,
        headers: {
          api_access_token: options.token,
          Accept: "application/json",
          ...(body === undefined ? {} : { "Content-Type": "application/json" }),
        },
        body: body === undefined ? undefined : JSON.stringify(body),
        signal: AbortSignal.timeout(options.timeoutMs),
      });
    } catch (error) {
      throw new ChatwootApiError(0, operation, (error as Error).name === "TimeoutError" ? "タイムアウト" : "接続できない");
    }
    // 応答の本文は個人情報を含みうるので、エラーのメッセージに入れない
    if (!res.ok) throw new ChatwootApiError(res.status, operation, `HTTP ${res.status}`);
    const text = await res.text();
    if (!text) return null;
    try {
      return JSON.parse(text);
    } catch {
      throw new ChatwootApiError(res.status, operation, "応答が JSON でない");
    }
  }

  return {
    async getConversation(conversationId) {
      const parsed = ConversationSchema.safeParse(await call("GET", `/${conversationId}`));
      if (!parsed.success) throw new ChatwootApiError(200, `GET conversations/${conversationId}`, "応答の形が違う");
      const last = parsed.data.last_non_activity_message;
      return {
        status: parsed.data.status,
        labels: parsed.data.labels ?? [],
        lastMessage: last ? { id: last.id, messageType: last.message_type, senderType: last.sender?.type ?? null } : null,
      };
    },

    async sendMessage(conversationId, reply, inReplyTo) {
      const body =
        reply.kind === "text"
          ? { content: reply.content, message_type: "outgoing", private: false, content_attributes: { in_reply_to: inReplyTo } }
          : {
              content: reply.content,
              message_type: "outgoing",
              private: false,
              content_type: "input_select",
              content_attributes: { items: reply.items, in_reply_to: inReplyTo },
            };
      await call("POST", `/${conversationId}/messages`, body);
    },

    async setLabels(conversationId, labels) {
      await call("POST", `/${conversationId}/labels`, { labels });
    },

    async setStatus(conversationId, status) {
      await call("POST", `/${conversationId}/toggle_status`, { status });
    },
  };
}

import type { QuestionEvent, SelectionEvent } from "../chatwoot/events.js";
import type { ChoiceItem, Reply } from "../chatwoot/types.js";
import { CHOICE, LABELS, MAX_CANDIDATES, MESSAGES } from "../constants.js";
import type { FaqItem } from "../faq/schema.js";
import type { FaqSnapshot } from "../faq/store.js";
import { normalize, type Ranked, rank } from "../matcher/index.js";

export interface Thresholds {
  readonly high: number;
  readonly low: number;
  readonly margin: number;
}

export type Decision = "answer" | "candidates" | "unmatched" | "handoff" | "resolved";

/** 1 回の応答で行うこと（仕様 7.2）。副作用は execute が行う */
export interface Action {
  readonly decision: Decision;
  readonly reply: Reply;
  readonly addLabels: readonly string[];
  readonly status: "open" | "resolved" | null;
  /** 答えた FAQ（answer）か、候補に出した FAQ（candidates）の id */
  readonly faqIds: readonly string[];
  /** 質問の 1 位のスコア（選択のときは null） */
  readonly topScore: number | null;
}

const choice = (title: string, value: string): ChoiceItem => ({ title, value });

/** 候補の見出し。同じ質問が複数のページにあるため、context を括弧で付ける（仕様 7.2） */
export function candidateTitle(item: FaqItem): string {
  return item.context ? `${item.question}（${item.context}）` : item.question;
}

/** 答えが実質同じか（正規化した一方が他方を含む）。正規化して空の答えは、何とも同じとみなさない */
export function sameAnswer(a: FaqItem, b: FaqItem): boolean {
  const x = normalize(a.answer);
  const y = normalize(b.answer);
  if (!x || !y) return false;
  return x.includes(y) || y.includes(x);
}

function answer(item: FaqItem, topScore: number | null): Action {
  return {
    decision: "answer",
    reply: {
      kind: "select",
      content: `${item.answer}\n\n${MESSAGES.answerLinkPrefix}${item.url}`,
      items: [choice(MESSAGES.choiceResolved, CHOICE.resolved), choice(MESSAGES.choiceHandoff, CHOICE.handoff)],
    },
    addLabels: [LABELS.answered],
    status: null,
    faqIds: [item.id],
    topScore,
  };
}

function handOff(decision: "unmatched" | "handoff", topScore: number | null): Action {
  return {
    decision,
    reply: { kind: "text", content: MESSAGES.handoff },
    addLabels: [decision === "unmatched" ? LABELS.unmatched : LABELS.handoff],
    status: "open",
    faqIds: [],
    topScore,
  };
}

/** 答えの同じ候補を 1 つにまとめる（先に出たほうを残す） */
function distinctAnswers(ranked: readonly Ranked<FaqItem>[]): Ranked<FaqItem>[] {
  const out: Ranked<FaqItem>[] = [];
  for (const r of ranked) if (!out.some((kept) => sameAnswer(kept.item, r.item))) out.push(r);
  return out;
}

function decideQuestion(text: string, snapshot: FaqSnapshot, t: Thresholds): Action {
  const ranked = rank(text, snapshot.index);
  const top = ranked[0];
  if (!top || top.score < t.low) return handOff("unmatched", top?.score ?? 0);
  // 2 位は、1 位と答えが実質同じ項目を飛ばして数える（仕様 7.2）
  const runnerUp = ranked.slice(1).find((r) => !sameAnswer(r.item, top.item));
  if (top.score >= t.high && top.score - (runnerUp?.score ?? 0) >= t.margin) return answer(top.item, top.score);
  const picks = distinctAnswers(ranked.filter((r) => r.score > 0)).slice(0, MAX_CANDIDATES);
  return {
    decision: "candidates",
    reply: {
      kind: "select",
      content: MESSAGES.candidatesPrompt,
      items: [...picks.map((r) => choice(candidateTitle(r.item), r.item.id)), choice(MESSAGES.choiceNone, CHOICE.none)],
    },
    addLabels: [],
    status: null,
    faqIds: picks.map((r) => r.item.id),
    topScore: top.score,
  };
}

function decideSelection(value: string, snapshot: FaqSnapshot): Action {
  if (value === CHOICE.resolved) {
    return { decision: "resolved", reply: { kind: "text", content: MESSAGES.resolved }, addLabels: [], status: "resolved", faqIds: [], topScore: null };
  }
  if (value === CHOICE.handoff) return handOff("handoff", null);
  const item = snapshot.byId.get(value);
  // ［どれにも当てはまらない］と、faq.json から消えた FAQ の id
  return item ? answer(item, null) : handOff("unmatched", null);
}

export function decide(event: QuestionEvent | SelectionEvent, snapshot: FaqSnapshot, thresholds: Thresholds): Action {
  return event.kind === "question" ? decideQuestion(event.text, snapshot, thresholds) : decideSelection(event.value, snapshot);
}

import type { ChatwootClient } from "../chatwoot/client.js";
import type { EventTarget } from "../chatwoot/events.js";
import { MESSAGE_TYPE_OUTGOING } from "../constants.js";
import type { Action } from "./decide.js";

export type Outcome = "done" | "not-pending" | "stale";

export interface ExecuteResult {
  readonly outcome: Outcome;
  readonly sent: boolean;
}

/**
 * 判定を Chatwoot に反映する（仕様 7.4）。送信の要否は会話の last_non_activity_message で決める:
 *   - 対象のメッセージがまだ最新 → 1 通送る
 *   - ボットの outgoing が対象より新しい → 送信は済んでいる（Chatwoot の送り直し）。ラベルとステータスだけやり直す
 *   - それ以外（訪問者がその後に発言した、など）→ 古いイベント。新しい発言はそのイベントで扱う
 * ラベル（付け替え）とステータスは冪等。どこかで失敗したら例外にする（仕様 8 節）
 */
export async function execute(
  client: ChatwootClient,
  target: Pick<EventTarget, "conversationId" | "messageId">,
  action: Action,
): Promise<ExecuteResult> {
  const view = await client.getConversation(target.conversationId);
  if (view.status !== "pending") return { outcome: "not-pending", sent: false };

  const last = view.lastMessage;
  let send: boolean;
  if (last?.id === target.messageId) send = true;
  else if (last && last.id > target.messageId && last.messageType === MESSAGE_TYPE_OUTGOING && last.senderType === "agent_bot") send = false;
  else return { outcome: "stale", sent: false };

  if (send) await client.sendMessage(target.conversationId, action.reply, target.messageId);
  const missing = action.addLabels.filter((label) => !view.labels.includes(label));
  if (missing.length > 0) await client.setLabels(target.conversationId, [...view.labels, ...missing]);
  if (action.status) await client.setStatus(target.conversationId, action.status);
  return { outcome: "done", sent: send };
}

import type { ChatwootClient } from "./chatwoot/client.js";
import { type BotEvent, InvalidEventError, parseEvent } from "./chatwoot/events.js";
import { verifySignature } from "./chatwoot/signature.js";
import type { Config } from "./config.js";
import { HEALTH_PATH, MAX_BODY_BYTES, SIGNATURE_TOLERANCE_SECONDS, WEBHOOK_PATH } from "./constants.js";
import { decide } from "./dialog/decide.js";
import { execute } from "./dialog/execute.js";
import type { FaqSource } from "./faq/store.js";

/** 入口に依存しない要求（ヘッダー名は小文字）。開発は server.ts、本番は lambda.ts が作る */
export interface HttpRequest {
  readonly method: string;
  readonly path: string;
  readonly headers: Readonly<Record<string, string | undefined>>;
  readonly body: Buffer;
}

export interface HttpResponse {
  readonly status: number;
  readonly body: string;
}

export type Handle = (req: HttpRequest) => Promise<HttpResponse>;

export interface HandlerDeps {
  config: Config;
  faq: FaqSource;
  client: ChatwootClient;
  nowSeconds?: () => number;
  log?: (entry: Record<string, unknown>) => void;
}

const json = (status: number, body: unknown): HttpResponse => ({ status, body: JSON.stringify(body) });

/**
 * Webhook を受けて判定し、Chatwoot に反映する（仕様 6〜8 節）。
 * 失敗（faq.json が無い・Chatwoot の API の失敗）は例外で投げる。入口が 502 にし、Chatwoot は会話を open にする。
 * ログは 1 件 1 行。メッセージの本文・氏名・メールアドレス・トークンは出さない
 */
export function createHandler(deps: HandlerDeps): Handle {
  const { config, faq, client } = deps;
  const nowSeconds = deps.nowSeconds ?? (() => Math.floor(Date.now() / 1000));
  const log = deps.log ?? ((entry: Record<string, unknown>) => console.error(JSON.stringify(entry)));
  const thresholds = { high: config.FAQ_MATCH_HIGH, low: config.FAQ_MATCH_LOW, margin: config.FAQ_MATCH_MARGIN };

  return async (req) => {
    const startedAt = Date.now();
    if (req.path === HEALTH_PATH) return req.method === "GET" ? json(200, { ok: true }) : json(405, { error: "method_not_allowed" });
    if (req.path !== WEBHOOK_PATH) return json(404, { error: "not_found" });
    if (req.method !== "POST") return json(405, { error: "method_not_allowed" });
    if (req.body.length > MAX_BODY_BYTES) return json(413, { error: "payload_too_large" });

    const signature = verifySignature({
      secret: config.CHATWOOT_BOT_SECRET,
      timestamp: req.headers["x-chatwoot-timestamp"],
      signature: req.headers["x-chatwoot-signature"],
      rawBody: req.body,
      nowSeconds: nowSeconds(),
      toleranceSeconds: SIGNATURE_TOLERANCE_SECONDS,
    });
    if (!signature.ok) {
      log({ t: new Date().toISOString(), level: "warn", result: "unauthorized", reason: signature.reason });
      return json(401, { error: "unauthorized" });
    }

    let payload: unknown;
    try {
      payload = JSON.parse(req.body.toString("utf8"));
    } catch {
      return json(400, { error: "invalid_json" });
    }
    let event: BotEvent;
    try {
      event = parseEvent(payload);
    } catch (error) {
      if (error instanceof InvalidEventError) return json(400, { error: "invalid_event" });
      throw error;
    }
    if (event.kind === "ignore") return json(200, { result: "ignored" });
    if (event.accountId !== config.CHATWOOT_ACCOUNT_ID) {
      log({ t: new Date().toISOString(), level: "warn", result: "ignored", reason: "account" });
      return json(200, { result: "ignored" });
    }

    const snapshot = await faq.current();
    const action = decide(event, snapshot, thresholds);
    const result = await execute(client, event, action);
    log({
      t: new Date().toISOString(),
      level: "info",
      conversation: event.conversationId,
      event: event.kind,
      decision: action.decision,
      top: action.topScore,
      faq: action.faqIds,
      outcome: result.outcome,
      sent: result.sent,
      ms: Date.now() - startedAt,
    });
    return json(200, { result: result.outcome });
  };
}

import { createChatwootClient } from "./chatwoot/client.js";
import type { Config } from "./config.js";
import { CHATWOOT_TIMEOUT_MS, FAQ_FETCH_TIMEOUT_MS } from "./constants.js";
import { FaqStore } from "./faq/store.js";
import { createHandler, type Handle } from "./handler.js";

export interface Runtime {

  readonly faq: FaqStore;
}

/** 部品を組み立てる。開発の入口（index.ts）と本番の入口（lambda.ts）で共有する */
export function createRuntime(config: Config, deps: { fetchImpl?: typeof fetch; log?: (entry: Record<string, unknown>) => void } = {}): Runtime {
  const faq = new FaqStore({
    url: config.FAQ_URL,
    refreshMs: config.FAQ_REFRESH_SECONDS * 1000,
    timeoutMs: FAQ_FETCH_TIMEOUT_MS,

    accountId: config.CHATWOOT_ACCOUNT_ID,
    token: config.CHATWOOT_BOT_TOKEN,
    timeoutMs: CHATWOOT_TIMEOUT_MS,
    fetchImpl: deps.fetchImpl,
  });
  return { faq, handle: createHandler({ config, faq, client, log: deps.log }) };
}

import http from "node:http";
import { MAX_BODY_BYTES, REQUEST_TIMEOUT_MS, SERVER_NAME } from "./constants.js";
import type { Handle } from "./handler.js";

/** 開発の入口（3107）。要求を HttpRequest に変えて handle を呼ぶ。例外は本番の関数 URL と同じく 502 にする（仕様 8 節） */
export function createDevServer(handle: Handle, log: (message: string) => void = (message) => console.error(message)): http.Server {
  const server = http.createServer(async (req, res) => {
    const send = (status: number, body: string) => {
      res.writeHead(status, { "Content-Type": "application/json; charset=utf-8", "Cache-Control": "no-store" });
      res.end(body);
    };
    try {
      // 上限を超えた分は捨てながら最後まで読む（途中で応答すると、送信中のクライアントの接続が切れて失敗する）
      const chunks: Buffer[] = [];
      let size = 0;
      for await (const chunk of req) {
        size += (chunk as Buffer).length;
        if (size <= MAX_BODY_BYTES) chunks.push(chunk as Buffer);
      }
      if (size > MAX_BODY_BYTES) return send(413, JSON.stringify({ error: "payload_too_large" }));
      const headers: Record<string, string | undefined> = {};
      for (const [name, value] of Object.entries(req.headers)) headers[name] = Array.isArray(value) ? value.join(", ") : value;
      const result = await handle({ method: req.method ?? "GET", path: (req.url ?? "/").split("?")[0] || "/", headers, body: Buffer.concat(chunks) });
      send(result.status, result.body);
    } catch (error) {
      log(`[${SERVER_NAME}] 処理に失敗した: ${(error as Error).name}: ${(error as Error).message}`);
      if (!res.headersSent) send(502, JSON.stringify({ error: "bad_gateway" }));
      else res.end();
    }
  });
  server.requestTimeout = REQUEST_TIMEOUT_MS;
  return server;
}

import { GetSecretValueCommand, SecretsManagerClient } from "@aws-sdk/client-secrets-manager";
import { loadConfig } from "./config.js";
import type { Handle, HttpRequest } from "./handler.js";
import { createRuntime } from "./runtime.js";

// 本番の入口（Lambda の関数 URL。payload format 2.0）。SAM の Handler は index.handler（bundle が dist-lambda/index.mjs を作る）
export interface FunctionUrlEvent {
  readonly rawPath?: string;
  readonly headers?: Readonly<Record<string, string | undefined>>;
  readonly body?: string;
  readonly isBase64Encoded?: boolean;
  readonly requestContext?: { readonly http?: { readonly method?: string } };
}

export interface FunctionUrlResult {
  statusCode: number;
  headers: Record<string, string>;
  body: string;
}

export function toRequest(event: FunctionUrlEvent): HttpRequest {
  const headers: Record<string, string | undefined> = {};
  for (const [name, value] of Object.entries(event.headers ?? {})) headers[name.toLowerCase()] = value;
  const body = event.body === undefined ? Buffer.alloc(0) : Buffer.from(event.body, event.isBase64Encoded ? "base64" : "utf8");
  return { method: event.requestContext?.http?.method ?? "GET", path: event.rawPath ?? "/", headers, body };
}

/** コールドスタートで 1 回だけ読む。値はログに出さない（名前だけ） */
export async function loadSecrets(client: SecretsManagerClient, prefix: string): Promise<{ token: string; secret: string }> {
  if (!prefix) throw new Error("SECRETS_PREFIX が未設定");
  const read = async (name: string) => {
    const out = await client.send(new GetSecretValueCommand({ SecretId: `${prefix}/${name}` }));
    if (!out.SecretString) throw new Error(`${prefix}/${name} に値が無い`);
    return out.SecretString;
  };
  const [token, secret] = await Promise.all([read("CHATWOOT_BOT_TOKEN"), read("CHATWOOT_BOT_SECRET")]);
  return { token, secret };
}

/** 初期化は最初の呼び出しで 1 回だけ（失敗したら次の呼び出しでやり直す）。handle の例外はそのまま投げる（Errors に数え、関数 URL は 502） */
export function createLambdaHandler(init: () => Promise<Handle>): (event: FunctionUrlEvent) => Promise<FunctionUrlResult> {
  let ready: Promise<Handle> | null = null;
  return async (event) => {
    ready ??= init().catch((error: unknown) => {
      ready = null;
      throw error;
    });
    const handle = await ready;
    const res = await handle(toRequest(event));
    return { statusCode: res.status, headers: { "Content-Type": "application/json; charset=utf-8", "Cache-Control": "no-store" }, body: res.body };
  };
}

async function defaultInit(): Promise<Handle> {
  const { token, secret } = await loadSecrets(new SecretsManagerClient({}), process.env.SECRETS_PREFIX ?? "");
  return createRuntime(loadConfig({ ...process.env, CHATWOOT_BOT_TOKEN: token, CHATWOOT_BOT_SECRET: secret })).handle;
}

export const handler = createLambdaHandler(defaultInit);
```

  /** ページの名前。同じ質問が複数のページにあるため、ボットの選択肢で見分けるのに使う */
  readonly context: string | null;
  readonly items: readonly FaqItemCopy[];
}

// marker の付け忘れに備えて、本文に残った印でも除く（未完成の回答を訪問者に返さない）
const UNFINISHED = /【要(記入|確認)】/;

export function faqPages(): readonly FaqPage[] {
  return [
    { key: 'top', path: '/', anchor: 'top-faq', context: null, items: TOP.faq.items },
    { key: 'pricing', path: '/pricing', anchor: 'pricing-faq', context: '料金', items: PRICING_PAGE.faq.items },
    ...SERVICE_ORDER.map((slug) => ({
      key: `services-${slug}`,
      path: `/services/${slug}`,
      anchor: 'detail-faq',
      context: SERVICE_CARDS[slug].title,
      items: SERVICE_DETAILS[slug].faq.items,
    })),
  ];
}

/** id は「ページ-元の順番（1 から）」。除いた項目も数えるので、印を外しても他の項目の id は動かない */
export function exportItems(page: FaqPage, siteUrl: string | URL): FaqExportItem[] {
  const url = new URL(`${page.path}#${page.anchor}`, siteUrl).href;
  return page.items.flatMap((item, index) =>
    item.marker || UNFINISHED.test(item.question) || UNFINISHED.test(item.answer)
      ? []
      : [{ id: `${page.key}-${index + 1}`, question: item.question, answer: item.answer, url, context: page.context }],
  );
}

export function buildFaqExport(siteUrl: string | URL, generatedAt: Date = new Date()): FaqExport {
  return {
    version: 1,
    generated_at: generatedAt.toISOString(),
    items: faqPages().flatMap((page) => exportItems(page, siteUrl)),
  };
}

async function ensureFaqBot(ctx) {
  const base = `${BASE_URL}/api/v1/accounts/${ctx.state.get("CHATWOOT_ACCOUNT_ID")}`;
  const adminToken = ctx.state.get("CHATWOOT_ADMIN_TOKEN");

  const list = await ctx.http("Chatwoot エージェントボット一覧", `${base}/agent_bots`, withToken(adminToken));
  const own = (Array.isArray(list) ? list : (list?.payload ?? [])).filter((bot) => !bot.system_bot);
  let bot = own.find((b) => String(b.id) === ctx.state.get("CHATWOOT_FAQ_BOT_ID")) ?? own.find((b) => b.name === FAQ_BOT_NAME);
  if (!bot) {
    bot = await ctx.http("Chatwoot エージェントボット作成", `${base}/agent_bots`, {
      method: "POST",
      ...withToken(adminToken),
      json: { name: FAQ_BOT_NAME, description: "Web サイトの FAQ に答えるボット（backend/faq-bot）", outgoing_url: FAQ_BOT_URL },
    });
    ctx.log(`エージェントボット「${FAQ_BOT_NAME}」を作った`);
  } else if (bot.outgoing_url !== FAQ_BOT_URL) {
    bot = await ctx.http("Chatwoot エージェントボット更新", `${base}/agent_bots/${bot.id}`, { method: "PATCH", ...withToken(adminToken), json: { outgoing_url: FAQ_BOT_URL } });

  if (!bot.access_token || !bot.secret) throw new Error("エージェントボットの access_token・secret が応答に無い（管理者のトークンで呼んでいるか確かめる）");

  ctx.state.set("CHATWOOT_FAQ_BOT_TOKEN", bot.access_token, { secret: true });
  ctx.state.set("CHATWOOT_FAQ_BOT_SECRET", bot.secret, { secret: true });

  const inboxId = ctx.state.get("CHATWOOT_INBOX_ID");

  const problems: string[] = [];

export interface WidgetMessage {
  id: number;
  content: string | null;
  message_type: number;
  content_type: string;
  content_attributes: { items?: { title: string; value: string }[]; submitted_values?: unknown[] } | null;

async function ok<T>(res: Response, label: string): Promise<T> {
  if (!res.ok) throw new Error(`${label}: HTTP ${res.status}`);
  const text = await res.text();
  return (text ? JSON.parse(text) : null) as T;
}

/** ウィジェットの公開 API で振る舞う訪問者（I-07 と同じ経路） */
export class Visitor {
  private constructor(
    private readonly state: DevState,
    private readonly auth: string,
    readonly contactId: number,
  ) {}

  static async create(state: DevState, name: string): Promise<Visitor> {
    const config = await ok<{ website_channel_config: { auth_token: string }; contact: { id: number } }>(
      await fetch(`${CHATWOOT}/api/v1/widget/config?website_token=${state.websiteToken}`, { method: "POST" }),
      "widget config",
    );
    const visitor = new Visitor(state, config.website_channel_config.auth_token, config.contact.id);
    // 消し残しを探せるように it- の名前を付ける
    await ok(await fetch(visitor.url("/api/v1/widget/contact"), { method: "PATCH", headers: visitor.headers(), body: JSON.stringify({ name }) }), "widget contact");
    return visitor;
  }

  private url(path: string): string {
    return `${CHATWOOT}${path}?website_token=${this.state.websiteToken}`;
  }

  private headers(): Record<string, string> {
    return { "X-Auth-Token": this.auth, "Content-Type": "application/json" };
  }

  async say(content: string): Promise<{ id: number; conversation_id: number }> {
    return ok(await fetch(this.url("/api/v1/widget/messages"), { method: "POST", headers: this.headers(), body: JSON.stringify({ message: { content, timestamp: new Date().toString() } }) }), "widget message");
  }

  async messages(): Promise<WidgetMessage[]> {
    const body = await ok<{ payload: WidgetMessage[] }>(await fetch(this.url("/api/v1/widget/messages"), { headers: this.headers() }), "widget messages");
    return body.payload;
  }

  async select(messageId: number, item: { title: string; value: string }): Promise<void> {
    await ok(await fetch(this.url(`/api/v1/widget/messages/${messageId}`), { method: "PATCH", headers: this.headers(), body: JSON.stringify({ message: { submitted_values: [item] } }) }), "widget select");
  }

export class Admin {
  constructor(private readonly state: DevState) {}

  private url(path: string): string {
    return `${CHATWOOT}/api/v1/accounts/${this.state.accountId}${path}`;
  }

  async conversation(id: number): Promise<{ status: string; labels: string[] }> {
    const body = await ok<{ status: string; labels: string[] }>(await fetch(this.url(`/conversations/${id}`), { headers: { api_access_token: this.state.adminToken } }), "conversation");
    return { status: body.status, labels: body.labels ?? [] };
  }

  async deleteContact(id: number): Promise<void> {
    await fetch(this.url(`/contacts/${id}`), { method: "DELETE", headers: { api_access_token: this.state.adminToken } });
  }
}

/** 条件を満たすまで待つ（Webhook は Sidekiq のジョブなので非同期） */
export async function waitFor<T>(probe: () => Promise<T | null | undefined | false>, label: string, timeoutMs = 20_000): Promise<T> {
  const deadline = Date.now() + timeoutMs;
  for (;;) {
    const value = await probe();
    if (value) return value;
    if (Date.now() > deadline) throw new Error(`待ちきれなかった: ${label}`);
    await new Promise((resolve) => setTimeout(resolve, 500));
  }
}

/** ボットの最新の input_select（または text）を待つ */
export const botMessage = (visitor: Visitor, predicate: (m: WidgetMessage) => boolean, label: string) =>
  waitFor(async () => (await visitor.messages()).filter((m) => m.message_type === 1).find(predicate), label);
