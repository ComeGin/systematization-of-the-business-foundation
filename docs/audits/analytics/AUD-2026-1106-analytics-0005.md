# 観測の補足

`execute-sql`（HogQL）で `$web_vitals` イベントの `properties.$web_vitals_{LCP,INP,CLS}_value` を p75 に集計した（`quantile(0.75)`）。標本数（値が非 NULL の件数）: LCP `n=239`、INP `n=117`、CLS `n=145`。いずれも 1 件以上あるため 3 指標とも `metrics` に記録した。

標本は **Cookie に同意した訪問者だけ**（posthog-js の `$web_vitals` 自動計測）。PostHog の Web 分析画面が出す p75（セッションの最初のページビューだけを対象）とは標本の取り方が異なるため、直接比較しない。

**欠測の徴候チェック**: GA4 側（`docs/audits/analytics/AUD-2026-1106-analytics-0001.md`）の `SESSION-count=20`（≥1）に対し、`$web_vitals` の標本も 3 指標とも 1 件以上存在する。どちらか一方だけが 0 という状態ではないため、AA-04 の暴走条件 #10（片方だけ 0 の欠測徴候）には該当しない。
