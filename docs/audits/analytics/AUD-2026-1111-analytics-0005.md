# 観測の補足

PostHog（本番用のプロジェクト）の `$web_vitals` イベントを `execute-sql` で p75 に集計した（個票は読んでいない。`persons`・`distinct_id`・`$session_id` は SELECT していない）。

```sql
SELECT
  quantile(0.75)(toFloat(properties.$web_vitals_LCP_value)) AS lcp_p75,
  quantile(0.75)(toFloat(properties.$web_vitals_INP_value)) AS inp_p75,
  quantile(0.75)(toFloat(properties.$web_vitals_CLS_value)) AS cls_p75,
  countIf(isNotNull(properties.$web_vitals_LCP_value)) AS lcp_n,
  countIf(isNotNull(properties.$web_vitals_INP_value)) AS inp_n,
  countIf(isNotNull(properties.$web_vitals_CLS_value)) AS cls_n
FROM events
WHERE event = '$web_vitals'
  AND toDate(toTimeZone(timestamp, 'Asia/Tokyo')) BETWEEN toDate('2026-10-05') AND toDate('2026-11-08')
```

標本数: LCP `n=261`、INP `n=134`、CLS `n=162`（いずれも 1 以上のため、各指標の `metrics` に値を書いた）。

**この標本は Cookie に同意した訪問者だけのものであり、PostHog の Web 分析の画面（セッションの最初のページビューだけの p75）とは標本の取り方が違う。**

欠測の徴候チェック: GA4 の (a) `AUD-2026-1111-analytics-0001` は `SESSION-count=38`（1 以上）で、本ファイルの標本もすべて 1 以上。片方だけ 0 になる組み合わせは無く、欠測の徴候は見られない。
