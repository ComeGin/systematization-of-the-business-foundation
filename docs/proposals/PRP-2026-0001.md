# 提案の説明

## 背景（根拠）

`AUD-2026-1116-quality-0001`（`source: quality`、項目 6 の WCAG 機械検査、`measured_at: 2026-11-16T01:15:16+09:00`、`fetch.outcome: ok`）で、`QC-a11y-serious` が 35 件観測された。対象は `/contact/thanks/` の `project: mobile` / `state: default` のみで `status: failed`（他 55 ページ〈desktop/mobile × 各ルート・状態〉はすべて `status: passed`）。違反は axe-core のルール `button-name`（`impact: critical`）で、iframe 内の繰り返しボタン（セレクタの連番パターンから同一構造の要素が 35 個）に読み上げ可能な名前が無い。公開サイトは JIS X 8341-3:2016 の AA 準拠を表明しており、この違反は直ちに解消すべき最優先事項である。

## 変更内容

`/contact/thanks/` のモバイル表示にある、埋め込み iframe 内の繰り返しボタン（予約カレンダー系ウィジェットと推定）に `aria-label` またはテキストコンテンツを付与し、axe-core の `button-name` 違反を解消する。ウィジェットの DOM を直接操作できない場合は iframe への `title` 属性付与を代替手段として検討する。配色・レイアウト・既存の機能には触れない。

## 期待する効果と判定

`QC-a11y-serious` を 35 → 0 にする。判定は `weekly-observe-a11y` による定期観測後の最初の月曜日（2026-11-23）の翌日である 2026-11-24 に `R3` が行う。

## リスクとロールバック

リスクは低い。変更は該当ページのボタンへのラベル付与のみで、表示・構造・他ページには影響しない。ロールバックは `rollback.procedure` のとおり `git revert` と通常のデプロイ手順で行う（`reversible: true`）。公開前に人がスクリーンリーダーで確認する運用に従う。
