# systematization-of-the-business-foundation

`SaaS`システムの販売事業`の`事業経営基盤`を`再帰的自己改善型`のシステムとして構築します。

## スキーム（運用体制と業務フロー）

- 役割の明確化: Webマスター（全体の構築・管理）、コンテンツディレクター（SEO・記事作成）、データアナリスト（CVR改善）の3つの役割・責任範囲を定義。

- 標準化された更新ワークフロー: 「企画 → 執筆/デザイン → 承認（ダブルチェック） → 公開」の手順を標準化し、情報の正確性確保と誤更新リスクを回避。

- 定期的なPDCA運用: 週次のコンテンツ投入・ABテスト、月次のGA4/MAデータに基づくCVR（コンバージョン率）改善会議の定例化。

- ガバナンス・セキュリティ運用: シングルサインオン（SSO）やアクセス権限制御を徹底し、担当者変更時の管理手順をマニュアル化。

- 役割分担の明確化:
  - SEOディレクター: 全体戦略、キーワード選定、カスタマージャーニー設計、KPI管理を担当。

  - コンテンツエディター/ライター: 記事構成案作成、取材、執筆、校正を実施。

  - エンジニア/Webデザイナー: サイト構造の最適化（テクニカルSEO）、表示速度改善、CTAデザインの実装。

- キーワード＆CV設計の標準化:
  - 検索意図を「潜在（課題探求）」「準顕在（手法比較）」「顕在・指名（サービス比較・導入検討）」に分類。

  - キーワードの温度感に合わせてCTA（ホワイトペーパー、無料トライアル、デモ予約など）を出し分け、MA/SFAへ即時トスアップするフローを構築。

- 定期的なPDCA運用:
  - 月次の順位・流入・CVR分析に基づき、過去記事のリライトや内部リンク構造の最適化を定例業務化。

## システム（組み込むツール群）

- CMS: Strapi
- MA: Strapi
- アクセス解析: Umami
- 行動分析 / ABテスト: PostHog
- Web接客 / チャット: Chatwoot
- フロントエンドフレームワーク / SSG: Astro
- ワークフロー自動化 / iPaaS: n8n
- SEO・パフォーマンス自動監査ツール: Google Search Console, Lighthouse CI

## 再帰的自己改善として模倣する組織・サービス

- インフラ・CDNサービス: Cloudflare, Vercel（表示速度の高速化、DDoS攻撃対策、SSLの自動化）。
- デザイン・制作基盤: Figma（プロトタイプ共有と共同編集）、Canva/Adobe CC（バナー・アイキャッチ制作）。
- SEO / マーケティングコンサル: 戦略立案やキーワード選定に関する専門知見の導入。
- 保守・セキュリティ代行: サーバー監視や障害時の緊急対応サポート。
- SaaS/BtoB特化型コンテンツ制作代行: 専門知識を要する業界記事やユーザー事例・取材記事作成の外部ライター・編集プロダクションの活用。
- テクニカルSEO開発代行: Core Web Vitals（表示速度）改善や構造化データ実装など、スポットで専門知識が必要な開発業務の外注。
